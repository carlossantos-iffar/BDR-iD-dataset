# BDR-iD dataset

A public dataset for research on diabetic retinopathy, organized into classification, object detection, and segmentation tasks.

You can download the dataset from GitHub or Google Drive:
- Available on Google Drive: [BDR-iD dataset](https://drive.google.com/drive/folders/1wwnIZB0dPlOyasdakdrSvRlBjwrLr0v7?usp=drive_link)
- Available on GitHub:
```bash
git clone https://github.com/carlossantos-iffar/BDR-iD-dataset.git
```
